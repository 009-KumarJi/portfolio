# Krishna Kumar — Systems Control Plane

> **[krishna.novitrail.com](https://krishna.novitrail.com/)**

Developer-first portfolio and distributed systems control plane built with Next.js 16 (Turbopack), React 19, Tailwind CSS v4, and Framer Motion. Engineered for engineering leaders and hiring teams, showcasing production work across **Agentic AI Infrastructures**, **Sub-millisecond AI Safety Firewalls**, and **High-Throughput AWS & OCI Cloud Topology**.

---

## ✨ Control Plane Sections

| Section | Description |
|---|---|
| **Telemetry Ribbon** | Glassmorphic top bar with live cluster beacon (`ap-south-1 | 200 OK | UP: 99.98% | p99: 12ms`), `[SFX: ACTIVE]` audio toggle, and `[⌘K Connect]` trigger |
| **00 // The Control Plane** | Engineer dossier with live status beacon, one-click copyable cURL health check, and a live Request Inspector terminal with scenario simulation (`Simulate Attack`, `Simulate PII`, `Reset 200 OK`) |
| **01 // Topology Execution Maps** | Interactive project architecture pipelines (`NoviSentinel`, `NoviConnect`, `Smart Media Pipeline`) with dynamic category filtering (`[All Nodes]`, `[Security]`, `[Compute]`, `[Persistence]`) |
| **02 // Telemetry & Benchmarks** | 4-card metric grid (<1.0ms, Multi-Region, 99.98%, 2x OCI Cert) + Real-time multi-curve SVG latency sparklines (`p50`, `p95`, `p99`) with time window filtering (`1h`, `24h`, `7d`) and hover crosshair |
| **03 // The Engine Room** | Authentic `/etc/system/capabilities.yaml` terminal configuration console with line numbers, syntax highlighting, and one-click YAML/JSON spec export |
| **04 // Production Changelog** | Continuous Git branch commit tree segregating **`[● FULL-TIME // PROD]`** (Accenture Associate Software Engineer) from **`[○ INTERNSHIP // STAGING]`** (Accenture & Envint Global) |
| **05 // Daemon Console & Footer** | Terminal disconnect card (`shutdown -h now? [Y/n]`) with one-click email copy action, daemon status ticker, and protocol signatures |
| **⌘K Command Palette** | Monospace command palette modal accessible via `⌘K` or `Ctrl+K` with keyboard-navigable actions and shortcuts |

## 🛠 Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **UI:** React 19, Framer Motion, Inline Web Audio Synthesizer
- **Styling:** Tailwind CSS v4
- **Fonts:** Next.js Google Fonts (`Inter` & `JetBrains Mono`)
- **Language:** TypeScript 5 (Strict Mode)
- **Deployment:** Vercel

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run the dev server with Turbopack
npm run dev

# Run production build
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
